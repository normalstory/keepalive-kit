# recipes

복사해서 쓰는 조각들. 프레임워크는 Next.js(App Router) 기준이나,
핵심은 "가벼운 쿼리 한 번"이라 어디로든 옮길 수 있다.

| 파일 | 역할 |
|------|------|
| `keepalive-route.ts` | 1차 — 플랫폼 크론이 호출. 시크릿 보호 |
| `wake-route.ts` | 2차·수동 — 외부 스케줄러/알림 버튼이 호출. **무인증·무해** |
| `vercel.json.snippet` | Vercel Cron 등록 |

## 왜 엔드포인트가 둘인가

하나로 합치고 시크릿을 외부 cron 서비스에 넘기면, **그 업체의 보안이 당신의 보안이
된다** (README 원칙 2). 무해한 쪽을 따로 파면 업체 선택이 신뢰 문제에서 가용성 문제로
내려온다.

둘 다 하는 일은 `select 1` 한 번으로 같다. 차이는 **누가 부를 수 있는가**뿐이다.
